## Notes

- 4U, about 18 kg before drives. Mount it directly above the UPS.
- Drives load from the top, so it has to slide out on rails to swap one.
- One full-length PCIe slot stays free. No GPU planned: Quick Sync covers Plex transcoding.
- Update the BIOS and CPU microcode before loading data; 14th-gen Core chips need it.
- The TL-SX1008 switch is unmanaged and can't bond ports, so one 10GbE link is enough.
- Single PSU, 1-year hardware warranty. Unraid support is the first point of contact.
