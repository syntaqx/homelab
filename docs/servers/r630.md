# Dell PowerEdge R630

The compute node. Racked but powered off.

> [!NOTE]
> The R630 stays off until the server rack's UPS is upgraded. The rack's CyberPower OR500LCDRM1U
> is rated 300 W and Darkrock already draws 186 W of it. See [power.md](../power.md).

## Hardware

- Dell PowerEdge R630 (1U)
- __Memory:__ 256GB DDR4 1866MHz
- __Storage:__ 3× [Dell 1.2TB 10K 12Gb/s SAS 2.5" HDD](https://amzn.to/3WtA3v0)
- __Management:__ iDRAC

## Plan (Phase 3)

- Proxmox VE for self-hosted apps, VMs and the occasional game server, taking that work off Unraid.
- 2× SSDs for VM storage alongside the SAS drives. SAS drives are expensive, so the rest of the bays
  fill with 1.2 TB disks over time.
- 10GbE to the TL-SX1008. Check the network daughter card first; if it's 1GbE-only, swap in a
  2×10GbE one.
- Power it on and off remotely through iDRAC; back VMs up to an NFS share on the X15.
