# Build-plan sheets

Exports of the two blueprint sheets that lay out the server-rack plan:

- **Sheet 01** · phased rack elevations (P0 existing → P3 compute)
- **Sheet 02** · network and data flow, X15 bay map, power budget, cost schedule

The master copies live on a private Claude Design canvas on claude.ai. To refresh these, open the
canvas, then **Share › Export** each artboard as PNG and save it here as `sheet-01.png` and
`sheet-02.png`.
